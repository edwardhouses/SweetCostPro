# SweetCostPro — página pública

Tres páginas estáticas para GitHub Pages (repo `edwardhouses/sweetcostpro`):

- `index.html` — inicio: qué hace la app, precio, contacto.
- `privacidad.html` — política de privacidad (datos en el equipo; copia en Drive solo a petición).
- `terminos.html` — términos (licencia permanente por equipo, respaldos responsabilidad del cliente).

Misma estructura que `~/workspace/mitienda-web/` y `~/workspace/combos-web/`, con la paleta rosada de SweetCostPro (#7b2949 / #fff8f6). La página es lo que Google pide para publicar la app en la consola (marca completa: inicio + privacidad públicas + dominio autorizado `edwardhouses.github.io`).
